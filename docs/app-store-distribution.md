Pass your Ontario G1 driving test on the first try with Excel Driving G1 — 
the most comprehensive G1 knowledge-test prep app built entirely on the 
official Ministry of Transportation Ontario (MTO) Driver's Handbook.

🎨 CLEAN, ACCESSIBLE DESIGN

## 7. App Review Information

### Sign-In Required
**No** — the app does not require an account or login.

### Demo Account
Not applicable.

### Notes for App Review Team
```
Excel Driving G1 is a self-contained iOS study app for the Ontario G1 
driving knowledge test. 

• All 352 questions are bundled in-app (no network requests for question data).
• The only network activity is for outbound links in Settings → Legal & Support 
  (Privacy Policy, Terms & Conditions, Support, App Guide) — these open in Safari 
  via url_launcher.
• All user data (bookmarks, progress, achievements) is stored exclusively in 
  SharedPreferences (NSUserDefaults) on the device. No user data is transmitted 
  to any server.
• No camera, microphone, location, or contacts permissions are requested.
• The app works fully offline.
• Language can be toggled between English and French within Settings.
```

## 13. App Store Connect — Step-by-Step Submission

1. **Open** [App Store Connect](https://appstoreconnect.apple.com)
2. **My Apps** → **+** → **New App**
   - Platform: iOS
   - Name: `Excel Driving G1`
   - Primary Language: English
   - Bundle ID: `com.excellearning.excelDrivingG1`
   - SKU: `EXCELDRIVINGG1-001`
3. **App Information** → Fill in subtitle, category, content rights
4. **Pricing and Availability** → Free, select territories
5. **Prepare for Submission (1.0.0)**:
   - Upload screenshots via drag & drop or Transporter
   - Paste description, keywords, URLs
   - Complete App Review Information section
   - Set version release to automatic or manual
6. **Build** → Click **+** next to Builds → Select the uploaded `.ipa`
7. **Export Compliance** → Select No for encryption
8. **Submit for Review**
